# Publication boundary

This repository is an architecture and proof-of-work showcase, not a source distribution of the commercial applications.

## Included

- Newly written architecture diagrams and reduced schema projections.
- Engineering decisions traced to inspected components.
- Synthetic, independently written boundary examples.
- Aggregate test-runner summaries with dated scope and counts.
- Public product links and already-public code links.

## Kept private

- Application implementations, full schema/migration dumps and client configuration.
- Environment files, credentials, tokens, database connection strings and signing material.
- Customer, employee, supplier, patient, payment or operational records.
- Deployment/project identifiers, storage object paths, signed URLs and infrastructure endpoints.
- Raw logs, screenshots, database exports and local filesystem paths.

Private source filenames are referenced only where useful for explaining component responsibilities. No original private implementation or private repository history is copied into this repository. The synthetic examples express selected invariants; their tests are a separate executable specification, not a substitute for the commercial application's tests.
